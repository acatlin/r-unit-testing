Mastery objectives

Each line below is something you can do once you have mastered a lesson. If you can do it without looking at the lesson page, tick it off. If you cannot, the table says where to practise.

How to read the tables

Every objective has two kinds of evidence. Doing is a “Try it” step, where you write or run code yourself. Recognition is a multiple-choice question, where you pick the right answer from four. Doing is the stronger evidence: an objective is mastered when you can do it, not when you can spot it.

  • L4-T2 is Lesson 4, “Try it” step 2.
  • L3-Q2 is Lesson 3, “Check yourself” question 2.
  • L2-W1 is Lesson 2, warm-up question 1 (the “From last time” quiz).

Words such as expectation, test and edge case are defined in the glossary.
